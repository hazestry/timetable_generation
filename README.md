# генератор расписания учебных заведений

## структура репозитория

```
.
├── timetable_generation.ipynb     # основной ноутбук: eda, обучение моделей, генерация
├── app.py                        # streamlit-приложение
├── generator.py                  # модуль генератора (используется приложением)
├── class-schedules.csv           # исходный датасет
├── requirements.txt              # зависимости
└── readme.md
```

## как запустить

установить зависимости:
```bash
pip install -r requirements.txt
```

открыть и выполнить весь ноутбук `schedule_generation.ipynb` от начала до конца - это создаст все `.pkl` файлы и предобработанные csv.

запустить веб-приложение:
```bash
streamlit run app.py
```

## источник данных

открытый датасет расписания университета `class-schedules.csv` - 200 строк, 17 колонок, реальные пары за семестры fall 2024 и spring 2025. содержит информацию о курсах, преподавателях, времени и аудиториях.


## streamlit-приложение

веб-интерфейс с 5 вкладками:

- **расписание** - таблица с фильтрами по предмету, дням, корпусу + экспорт в csv
- **сетка недели** - heatmap «день недели × час начала», топ загруженных слотов
- **по корпусам** - heatmap «предмет × корпус», визуализация качества размещения
- **сравнение с/без ml** - параллельный запуск обоих режимов с метриками и графиками
- **о моделях** - краткая информация о каждой ml-модели и её метриках


## стек

- python 3.10+
- pandas, numpy — данные
- scikit-learn — модели (без глубокого обучения, согласно требованиям задания)
- matplotlib, seaborn — визуализации
- joblib — сериализация моделей
- streamlit — веб-интерфейс
